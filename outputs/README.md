# Pipeline Outputs

This directory contains all outputs generated by the data valuation pipelines. Each run writes to `{modality}/{task}/{dv}/`.

## Directory Structure

```
outputs/
├── xray/class/shap/                  # KNN-Shapley pipeline outputs
│   ├── output.txt                    # Full pipeline log
│   ├── hpo_trials.csv                # Hyperparameter search results
│   ├── train_val_loss.png            # Training/validation loss curves
│   ├── val_auc.png                   # Validation AUC over epochs
│   ├── densenet121_multilabel.pt     # Best model checkpoint
│   ├── embeddings_train.npz          # 1024-dim train embeddings + labels
│   ├── embeddings_val.npz            # 1024-dim val embeddings + labels
│   ├── knn_k_optimization.png        # KNN k selection plot
│   ├── shapley_values.npy            # Per-sample data values
│   ├── shapley_values_with_ids.csv   # Data values with image filenames
│   ├── shapley_histogram.png         # Distribution of data values
│   ├── retraining_curves.png         # 2-panel retraining (Top/Bottom/Random-N)
│   ├── retraining_all_metrics.png    # 2x3 grid (AUC+Loss x Train/Val/Test)
│   ├── subset_results.csv            # All subset experiment metrics
│   └── final_report.txt              # Full summary report
│
└── xray/class/ot/                    # Optimal Transport pipeline outputs
    ├── output.txt                    # Full pipeline log
    ├── hpo_trials.csv                # Hyperparameter search results
    ├── train_val_loss.png            # Training/validation loss curves
    ├── val_auc.png                   # Validation AUC over epochs
    ├── densenet121_multilabel.pt     # Best model checkpoint
    ├── embeddings_train.npz          # 1024-dim train embeddings + labels
    ├── embeddings_val.npz            # 1024-dim val embeddings + labels
    ├── ot_values.npy                 # Per-sample data values
    ├── ot_values_with_ids.csv        # Data values with image filenames
    ├── ot_histogram.png              # Distribution of data values
    ├── retraining_curves.png         # 2-panel retraining (Top/Bottom/Random-N)
    ├── retraining_all_metrics.png    # 2x3 grid (AUC+Loss x Train/Val/Test)
    ├── subset_results.csv            # All subset experiment metrics
    └── final_report.txt              # Full summary report
```

## Notes

- Model checkpoints (`.pt`) and embeddings (`.npz`) are large and should not be committed to git.
- Plots (`.png`), CSVs, and reports are small and safe to track.
- Both pipelines share Sections 1-3 and 5; only Section 4 (data valuation method) differs. See [pipeline architecture](../src/README.md).
